kick

An omnibus project management tool. Kick makes sure all your projects have a valid configuration, up-to-date dependencies and a consistent style. It works without configuration in any standalone git repository, is nondestructive by default (changes are staged for review), and is highly configurable when you want it to be.

Install

curl -fsSL https://udoprog.github.io/kick/install.sh | sh

Installs the latest release into ~/.local/bin (set KICK_INSTALL_DIR to change it, or KICK_VERSION to a release tag such as 2026-05-04 to pin one) on Linux and macOS. On Windows, download the zip from the releases. Once installed, kick update upgrades kick itself.
